# Читательская библиотека

Главный жест — вход в раздел через стеллаж. Не игровая 3D-комната: спокойная архитектурная перспектива, настоящие доступные кнопки, понятный выход. При reduced-motion переход мгновенный.

Палитра: бумага #f4f0e7, текст #302f2a, дерево #49433b, тень #262622, шалфей #737b68, приглушённый бордовый #796360. Шрифты: локальная Literata для чтения, Cormorant Garamond для заголовков, системный sans для управления.

```
Пергамин                         Поиск · Добавить книгу · Мастерская
Библиотека                       Все / Хочу / Читаю / Прочитано
Продолжить чтение: автор — название                         Читать →
[ Классика ] [ Фантастика ] [ Детям ] [ История ] [ Поэзия ]
   корешки      корешки     корешки    корешки     корешки
```

Клик по разделу: приближение стеллажа, реальные книги с полными подписями при фокусе/наведении, сортировка по автору или названию, переключатель списка. Пустое состояние объясняет импорт, а не маскируется декоративными книгами.

Читатель отделён от рукописей и не редактирует оригинал. Локатор — номер главы и индекс текстового блока, а не номер экрана. Настройки размера и ширины не сбрасывают место. Закладки и заметки хранятся рядом с читательской книгой. Источник и условия использования доступны из карточки.

Данные — отдельная IndexedDB. Переносимая JSON-копия включает тексты, изображения, оригинальные файлы, полки, заметки, настройки и прогресс. Восстановление добавляет отсутствующие книги, не перезаписывает существующие. Облачная синхронизация/аккаунты не подразумеваются.

Стартовая подборка — оригинальные произведения давно умерших авторов; никаких современных переводов и иллюстраций. На каждый текст сохраняется ссылка на источник и лицензия сайта. Доступность в интернете сама по себе не разрешает перепубликацию.
