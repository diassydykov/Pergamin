# Пергамин — живая книга

Локальный редактор художественных книг: вместо белого листа — «живая книга»
с пергаментными листами, корешком, буквицей и орнаментами. Всё работает на
вашем устройстве; интернет нужен только для генерации ИИ-иллюстраций.

## Состав
- `index.html`, `book.css`, `book.js` — оболочка: книга, панель инструментов,
  библиотека книг, автосохранение (IndexedDB, база `pergamin`).
- `studio.js` — история версий, структура рукописи, редакторские заметки,
  импорт и обработка изображений, EPUB/DOCX и мастер печати.
- `ai.js` — модуль ИИ-иллюстраций: промт с учётом стиля книги и её истории
  иллюстраций, генерация (pollinations.ai, Flux), вставка рисунка в рукопись.
- `sw.js` — service worker: офлайн-режим (оболочка + шрифты + иконки кэшируются).
- `fonts/` — Cormorant Garamond, EB Garamond, Caveat (OFL, Google Fonts).
- `icons/`, `manifest.webmanifest` — PWA: установка как приложение.
- `Pergamin.exe` — Windows-приложение без консольного окна и без зависимости от Python.
- `start.bat` — совместимый запуск `Pergamin.exe` в один клик.
- `desktop-launcher/` — исходник и иконка Windows-лаунчера.

## Запуск на компьютере (Windows)
1. Откройте ярлык **«Пергамин»** на рабочем столе или запустите `Pergamin.exe`.
2. Приложение само открывает книгу в отдельном окне Chrome/Edge без адресной строки. Окно сервера и командная строка больше не появляются.
3. После закрытия окна книги скрытый локальный процесс завершается автоматически.
4. Профиль браузера и все книги хранятся в папке `pergamin-data` рядом с программой (в текущей установке: `E:\pergamin\pergamin-data`). Не удаляйте эту папку. Для переноса используйте **«Книга → Копия библиотеки»**, а на другом устройстве — **«Книга → Восстановить»**.

Python для обычного запуска больше не требуется: он уже упакован внутрь `Pergamin.exe`. Встроенный локальный компонент доступен только на `127.0.0.1` и не открывает приложение для других устройств в сети.

## Ярлык
Готовый ярлык создан по адресу `E:\UserFolders\Desktop\Пергамин.lnk`. Его можно перемещать по рабочему столу, закреплять в меню «Пуск» или на панели задач. Сам файл `Pergamin.exe` и папку `E:\pergamin` перемещать отдельно нельзя: рядом находятся файлы интерфейса и локальная библиотека.

## Как работает
- **Панель сверху**: отдельная строка книги и строка форматирования, библиотека,
  «+ Новая», шрифты Cormorant Garamond / EB Garamond / Literata / Lora /
  Vollkorn / рукописный Caveat / Georgia, размер
  15–30, B/I/U, «⇥» (отступ), стиль текста (абзац / «Глава» / подзаголовок),
  наклон заголовков, выравнивание (лево / центр / право), 4 оттенка бумаги,
  режим «Страницы» (1 страница / 2 страницы), линейка отступов,
  кнопка ИИ-иллюстрации, индикатор сохранения.
- **Отступ «⇥»** — вставляет отступ в начале строки (работает как во
  Word). Кнопка и клавиша работают одинаково.
- **Горячие клавиши** (внутри рукописи): Ctrl+B — жирный, Ctrl+I — курсив,
  Ctrl+U — подчёркивание, Ctrl+L / Ctrl+E / Ctrl+R — выравнивание
  по левому / центру / правому краю, Ctrl+J — по ширине, Ctrl+S —
  сохранить. Подсказка с клавишами показывается при наведении на кнопку.
- **Режим страниц**: в панели «Страницы» выберите «1 страница» (одна
  страница, как в тетради) или «2 страницы» (разворот — две страницы
  рядом с корешком посередине, название книги вверху на обеих, нумерация
  1 слева / 2 справа). Выбор запоминается.
- **Линейка** (кнопка «☰» справа в панели) — как в Word, ВНЕ книги, с двух
  сторон. Сверху — горизонтальная линейка с тремя перетаскиваемыми маркерами:
  левый отступ, отступ первой строки, правый отступ (значения видны справа на
  линейке, например `40 · 24 · 0`). Слева — вертикальная линейка: на ней
  показана строка, где стоит каретка. Поставьте курсор в абзац и тяните
  маркеры мышью — отступы этого абзаца меняются. Двойной клик по маркеру
  сбрасывает его отступ. В режиме «2 страницы» линейка работает относительно
  той страницы, где стоит курсор (маркеры не пересекают корешок).
  Отступы сохраняются вместе с текстом.
- **Автосохранение** — через 0,5 с после ввода; при переключении/закрытии
  книги незавершённый ввод тоже сохраняется.
- **Навигатор** — вкладки «Главы», «Заметки» и «Версии». Заголовки «Глава» и
  «Подзаголовок» автоматически образуют структуру; клик переносит к нужному месту.
- **История версий** — ручные и автоматические локальные снимки открытой книги
  (интервал 1/5/15/30/60 минут, до 50 снимков на книгу). При восстановлении
  текущая редакция сначала сохраняется отдельным снимком. Таймер работает, пока
  запущен Пергамин; версии находятся в локальной базе `pergamin-studio`.
- **Редакторские заметки** — выделите фрагмент, нажмите «+ Заметка», добавьте
  комментарий. Заметку можно закрыть как выполненную, вернуть или удалить.
- **Проверка орфографии** — язык выбирается в верхней панели: русский,
  қазақша или English. Используется словарь Chrome/Edge, установленный в системе.
- **Фокусный режим** — кнопка «Фокус» или F9 скрывает панели и статистику;
  повторный F9 либо Esc возвращает обычный режим.
- **Поиск по книге** — кнопка `⌕` или Ctrl+F. Результаты показываются с контекстом; клик переносит курсор к найденному фрагменту.
- **Статистика и цель** — над книгой отображаются слова, знаки, примерное время чтения и прогресс личной цели по словам. Цель хранится отдельно для каждой книги.
- **Меню «Книга»**:
  - переименование и безопасное удаление книги;
  - экспорт открытой книги в автономный HTML, EPUB и DOCX;
  - мастер печати/PDF с форматом страницы, полями, кеглем, титулом и нумерацией;
  - JSON-копия всей библиотеки вместе с оформлением и иллюстрациями;
  - восстановление библиотеки с проверкой файла и очисткой потенциально опасного HTML;
  - ручное создание версии и подключение Pollinations BYOP.
- **Работа с иллюстрацией**: щёлкните рисунок и тяните его в любую точку страницы.
  Восемь маркеров по сторонам и углам меняют размер с сохранением пропорций.
  В плавающей панели доступны обтекание, кадрирование, поворот, порядок слоёв,
  сброс, повторная генерация и удаление. Свой PNG/JPEG/WebP/GIF/AVIF до 20 МБ
  добавляется кнопкой «Изображение».
- **ИИ-иллюстрация**: подключите аккаунт через «Книга → Подключить генерацию»,
  выделите текст → «✦ Иллюстрация» → рисунок появляется
  прямо в книге без подписи и сохраняется для офлайн-просмотра.
  - Промт учитывает: заданный стиль книги (обязательно для всех рисунков),
    контекст всей книги, последние 3 иллюстрации книги («не противоречь им»).
  - Новая книга → чистый контекст: её первая иллюстрация задаёт стиль,
    который автоматически фиксируется; рисунки других книг не учитываются.
  - Продолжение старой книги → старые иллюстрации и стиль учитываются.
  - Сгенерированные картинки **вшиты в книгу** (dataURL) — видны и офлайн.

## Офлайн
Без интернета: писать, редактировать, оформлять, переключать книги, видеть
ранее сгенерированные иллюстрации, версии, экспорт и заметки — всё работает.
Кнопка «✦ Иллюстрация» отключена без интернета и без OAuth-сеанса.

## Подключение Pollinations BYOP
1. Откройте «Книга → Подключить генерацию» и скопируйте показанный адрес возврата.
2. На `enter.pollinations.ai/keys` создайте публичный App Key (`pk_…`), включите
   BYOP и укажите этот адрес как разрешённый redirect URI. Для Windows-приложения это обычно
   `http://127.0.0.1:8321/`.
3. Вставьте App Key в Пергамин и нажмите «Подключить через Pollinations».
4. Подтвердите доступ на стороне Pollinations. OAuth 2.1 + PKCE вернёт временный
   пользовательский токен; он хранится только в `sessionStorage` и исчезает после
   закрытия приложения. Секретный ключ в Пергамин вводить не нужно.

## Технические заметки
- Контракт оболочки ↔ ИИ-модуль: 8 методов `window.__pg__`
  (`currentBookId()`, `getBook`, `updateBook`, `getSelectionText`,
  `insertFigureAtSelection`, `isOnline`, `toast`, `on`) — см. SPEC.md.
- При изменении файлов поставки увеличьте версию `CACHE` в `sw.js`.
- Генерация: `gen.pollinations.ai/image`, OAuth 2.1 Authorization Code + PKCE,
  модель Flux с резервной Turbo, 768×768, новый seed на каждую генерацию. Токен
  хранится только в `sessionStorage`; в книги, версии и бэкапы не попадает.
- Живой сетевой smoke-тест: задайте `PERGAMIN_POLLINATIONS_KEY`, затем запустите
  `PERGAMIN_LIVE_AI=1 npm run test:e2e` (PowerShell: две переменные через `$env:`).

## Обновление 29.09.2026

- Разворот теперь листается как горизонтальные страницы-колонки: `#ms-scroll`
  остаётся фиксированным окном, `#ms` получает `column-width`, `column-fill:auto`
  и листается по `scrollLeft`. Вертикальный `scrollTop` больше не является
  источником пагинации.
- При наборе текста каретка сама ведёт разворот: левая страница заполняется вниз,
  затем текст течёт в правую страницу; когда заполнен весь видимый разворот,
  запускается перелистывание на следующий.
- Линейка считает ширину активной страницы в текущем развороте и не пересекает
  корешок.
- В меню «Книга» добавлены авторские метаданные и зашифрованная копия библиотеки
  (`PBKDF2-SHA256` + `AES-GCM`, файл `.pgenc`).
- Заметки сохраняют не только цитату, но и контекстный якорь, чтобы легче
  находить фрагмент после переработки абзаца.
- Добавлен базовый режим правок: вставки/удаления помечаются в тексте, затем их
  можно принять или отклонить.
- EPUB/DOCX экспорт добавляет автора, оглавление по заголовкам и очищает
  редакторские правки перед публикацией.

- **Редактура**: частые слова, длинные предложения, прирост слов за сеанс.
